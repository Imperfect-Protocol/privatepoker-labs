# Genesis — TypeScript/WebGPU port of Skynerd

The browser-native, GPU-accelerated next stage of the Skynerd drone swarm.
The design brief lives beside this folder: `SKYNERD_Genesis_Design_Brief.docx`.

## Folder contract

- **`../skynerd/`** — the Python reference simulator. It stays the source of
  truth; behavioural changes happen there first. Its `golden/` harness
  captures the reference behaviour.
- **`reference/golden-baseline.json`** — frozen Python behaviour, captured by
  `skynerd/golden/capture.py` (schema `skynerd-golden/1`). The TypeScript
  implementation validates itself against this document. Do not edit by hand:
  re-capture with Python when the reference changes.
- **TypeScript application code** — developed here.

## Golden baseline (Milestone 0)

Captured with Python 3.14.6 / NumPy 2.5.4. Contains four scenarios with
fixed seeds — `learn_to_fly` (30 blank-policy episodes), `waves` (5 carpet
waves with distributed inheritance), `school` (14 graded lessons + graduate
tensor size), `will_flight` (one willed life) — plus the agreed clocks:

| Clock | Value | Note |
|---|---|---|
| Physics | 50 Hz (dt 0.02 s) | hardcoded in `flight.py`, fixed dt |
| Decision window | 0.2 s | every 10 physics ticks |
| Motion | 10 Hz | neighbour recomputation |
| Vision | 2 Hz | radar raycast + SwarmEye push |
| Episode horizon | 20.0 s | hardcoded in `flight.py` |

Determinism proof: two captures of the same commit match exactly
(`skynerd/golden/compare.py`, zero tolerance). Port comparisons run with
`--tol` and agreed tolerances per milestone.

## Port milestones (from the brief)

1. **TypeScript core — IN PROGRESS → Milestone 1 done.** `src/core/` (Vec3,
   Heading, Quaternion, binning, RangeBins, Config, World coordinates),
   `src/net/` (Signal, Message, EventQueue, StunTimer). Validated by
   153 checks in `test/`: unit properties + numeric comparison against
   `reference/vector-ref.json` (generated by `skynerd/golden/vector_ref.py`)
   and the config/clock values against `reference/golden-baseline.json`.
   Run: `npm test` (or `tsc -p tsconfig.json && node build/test/run.js`).
2. WebGPU foundation — WGSL pipelines, CPU reference path, fallback
3. **One drone in browser — Milestone 3 done.** `src/physics/` (rigid body,
   aero tables/forces/moments, servo slew), `src/learning/` (instruments,
   dense reward, outcome classification, sparse Hebbian tensor reward/score,
   ServoPolicy choose/command/reinforce, flyEpisode) and `src/core/rng.ts`:
   an exact emulation of NumPy's PCG64 Generator (128-bit LCG + XSL-RR +
   Lemire bounded integers, empirically reverse-engineered and frozen in
   `reference/rng-ref.json`). Validated against
   `reference/flight-ref.json` (generated by `skynerd/golden/flight_ref.py`):
   six fixed-command physics trajectories exact at 1e-9; three full
   episodes of one learned policy (blank start, seeds 1007-1009, including
   a greedy pass) reproduce exactly — outcome, survival tick, every
   decision choice, final state, and the learned tensor afterwards
   (float32 slots included). The comparison itself caught a real port bug:
   JS `for` leaves the loop counter one past Python's `range`, silently
   adding a 1001st tick to surviving episodes.
4. **Hebbian swarm — Milestone 4 done (waves path).** `src/learning/flock.ts`
   (mosaic births, survivor shards, death screams with witness probability,
   newest-slot float32 merges) and `src/mission/carpet.ts` (WaveRunner), plus
   `choice`/`permutation` in `src/core/rng.ts` — NumPy's Floyd-with-hash-set
   plus result shuffle, and masked-rejection Fisher-Yates, both
   reverse-engineered empirically and frozen in `reference/rng-ref.json`.
   Acceptance gate: the TS port replays the Python golden `waves` scenario
   (seed 42, 5 waves of 8, ε=0.05, no school/will) EXACTLY — every per-drone
   survival second, death count, and flock size, across mosaic inheritance,
   obituary screams, and shared-RNG draw ordering. Remaining M4 surface:
   the dormant wavelet denoise pipeline (`denoise()` has no callers in the
   Python today) and the school/will/tactics layers for later milestones.
5. SwarmEye LVM — 512×256×8 layered depth maps
6. 3D viewport — third-person swarm camera, inspection overlays
7. Swarm Commander — Nebius LLM intents, validator, command panel
8. Genesis Town — digital twins: humans, cinema, shops, buses, buildings

## Notes

- Zero npm dependencies: the compiler is the system `tsc`, tests run on
  Node's module loader. `types-node.d.ts` holds minimal ambient declarations
  for the Node APIs tests use — delete it once `@types/node` is installed.
- Determinism contract: same-time events dispatch in scheduling order
  (FIFO tie-break via insertion sequence), matching the Python heap.
- Reference regeneration (run from `../skynerd/`):
  `python golden/capture.py --out ../skynerd_genesis/reference/golden-baseline.json`,
  `python golden/vector_ref.py`, `python golden/rng_ref.py`,
  `python golden/flight_ref.py`.
